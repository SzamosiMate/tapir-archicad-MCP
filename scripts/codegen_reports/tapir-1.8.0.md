# Tapir 1.8.0 codegen record

MultiConn moves from 0.9.6 to 0.9.7 and Tapir from 1.7.3 to 1.8.0. The tagged Tapir inventory grows from 425 to 640 commands, with 58 existing contracts changed. The Official inventory stays at 73. The MCP registry grows from **456 to 669 tools** (615 Tapir and 54 Official), with **213 new public names**.

- Restore both revision getters. The released schemas use aligned lists of successes or errors and require the plural `revisionChanges`. The element writer now extracts element IDs. Both response lists are paginated.
- Keep Official classification system and element lookups for their equivalent data and the flat element pagination. Exclude Tapir's narrower attribute classification getter because its success payload disagrees with its published model. Use `GetClassificationsOfAttributes`. [Active schema-exclusion reference](../../.agents/skills/tapir-mcp-codegen/references/schema-exclusions.md)
- Map the extended MEP category to `mep` and element user data to `custom_data`. Page large reads and extract the optional previews and GDL picture arrays from `GetLibraryPartPictures` as MCP images.
- Exclude `RemoveLibrariesFromBIMcloud` by maintainer decision because it removes shared server libraries that other projects can use. `ResetLibraries` remains exposed. Graphisoft describes a non-undoable library reset. In the Archicad 28 solo test project, the reset removed the local archive link and retained the Embedded Library and a probe PNG through a library reload. Embedded behavior beyond this setup remains undocumented.
