# Tapir 2.0.1

Updated multiconn 0.10.0 → 0.10.1 and Tapir 2.0.0 → 2.0.1 using the published distribution and exact release metadata. Upstream commands increase from 861 to 903 (Tapir 788 → 830; Official stays at 73). Generated tools increase from 800 to 842 (Tapir 752 → 794; Official stays at 48), plus the existing custom `elements_query` tool. All 42 new commands are exposed; none are removed, newly excluded or restored. The release also changes 85 Tapir contracts transitively.

The additions cover element/default field access, typed property values, profile values and railing patterns; angle/radial dimensions, pictures and change markers; element recreation and MEP route rebuilding; story editing and file merging; cameras, 3D Documents, interior elevations, layout subsets, layer settings and one-direction trim removal. Field access uses Archicad 29/30 DevKit definitions; default design-option discovery requires Archicad 29 and can use two temporary slab undo steps. Recreation workflows retain their upstream descriptions of new GUIDs and settings or associations they cannot preserve.

All additions use existing category mappings. Six new readers and eight affected readers receive top-level pagination for field inventories, nested values, property matrices, primitives, profiles, roof planes, dimensions and analytical loads; a single nested item can still be large. No new returned base64-image shape needs extraction. Existing exclusions remain: typed values complement formatted property strings, field definitions expose element fields beyond MCP command-schema discovery, and Tapir's richer navigator/profile responses still justify preferring them over Official. `SetCurrent3DStyle` still refuses in the [2.0.1 implementation](https://github.com/ENZYME-APD/tapir-archicad-automation/blob/2.0.1/archicad-addon/Sources/3DProjectionCommands.cpp); its retirement condition remains in [schema-exclusions.md](../../.agents/skills/tapir-mcp-codegen/references/schema-exclusions.md).

The preflight helper now distinguishes custom registrations from generated ones while retaining duplicate, stale-source and schema checks. No human decisions are pending.
