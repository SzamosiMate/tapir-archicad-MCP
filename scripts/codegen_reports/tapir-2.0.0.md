# Tapir 2.0.0 / multiconn 0.9.8

Updated multiconn 0.9.7 → 0.9.8 and Tapir 1.8.0 → 2.0.0 using published distributions and exact release-tag metadata. Upstream counts: Tapir 640 → 788 (+148), Official 73 → 73. Registered tools: 669 → 802 (Tapir 615 → 753, Official 54 → 49), exposing 133 new commands. Component-property values switch source and prefix; the other four source replacements preserve their public names.

- Prefer Tapir for 2D bounding boxes across drawing elements/databases, attribute/folder/navigator deletion with dry-run checks, and component-property values. The latter follows the maintainer's property-ID compatibility choice; Official coverage of all Tapir-returned IDs is unproven. Keep Official component listing for its equivalent identifier contract.
- Exclude `GetCommands` to keep agents within curated MCP discovery. Exclude ten new settings/picker dialogs under the existing application-UI policy and the unavailable `SetCurrent3DStyle`; its refusal and retirement condition are tracked in [schema exclusions](../../.agents/skills/tapir-mcp-codegen/references/schema-exclusions.md#setcurrent3dstyle). The old attribute-classification wrapper defect is fixed; that command remains excluded solely because `GetClassificationsOfAttributes` supplies its information.
- Add pagination only for broad library searches, criteria-based element listing, favorite contents, library 2D primitives, missing-attribute references and unused library parts. Reassess the previous Tapir 1.8.0 update’s 33 additions: retain creation-order element listing, analytical member details and element connections; remove the other 30 small, nested or partially paged responses. Total configured commands: 62. Component-property pagination moves to Tapir unchanged: one outer list only. Multiple sibling lists and nested payloads remain unbounded; no multi-field pagination is supported. ConvertImages adds flat image-wrapper extraction for PNG/JPEG; other formats preserve raw JSON.
- Retain license details and project-name resolution. Existing destructive-command decisions are preserved; no new human decision is pending.
